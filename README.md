# HOYO AIO

원신과 붕괴: 스타레일의 글로벌 호요랩 출석을 관리하는 Chrome Manifest V3 확장프로그램입니다.

## 현재 기능

- 원신·스타레일 개별 선택 및 수동 출석
- 사용자가 켜는 자동출석 (초기 설정: 꺼짐)
- 크롬 시작·팝업 열기·30분 주기 알람에 따른 출석 확인
- 한국 시간 오전 1시(UTC+8 자정)를 기준으로 날짜 변경
- 출석 완료 여부를 서버에서 재조회한 뒤 결과 저장
- 오늘 출석 완료한 게임의 자동 요청 생략
- 네트워크 오류는 최소 1시간 후 자동 재시도
- 로그인 만료·보안 인증·기타 API 오류는 반복 요청 대신 공식 페이지 안내
- 게임별 결과, 마지막 확인 시간, 이번 달 출석 일수 표시

가챠 기록, 프로필 동기화, 전적 조회, 디스코드 연동은 아직 구현하지 않았습니다.

## 크롬에 설치하기

Chrome 120 이상을 사용하세요. 확장프로그램 실행에는 Node.js나 빌드 작업이 필요하지 않습니다.

1. 이 저장소를 내려받습니다.
2. 크롬에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. 저장소의 **extension 폴더**를 선택합니다. 이 폴더 바로 아래에 `manifest.json`이 있습니다.
6. 확장프로그램 팝업에서 각 게임의 **공식 출석 페이지**를 열고 호요랩에 로그인합니다.
7. 원하는 게임을 선택한 뒤 **선택한 게임 지금 출석하기**로 먼저 확인합니다.
8. 정상 동작을 확인한 후 **자동출석**을 켭니다.

배포 ZIP을 사용할 경우, 먼저 압축을 풀고 `manifest.json`이 들어 있는 폴더를 로드하세요.

확장프로그램은 현재 해당 크롬 프로필에 로그인한 호요랩 계정 하나를 사용합니다. 계정을 변경하거나 로그인을 다시 했다면 **지금 출석하기**를 눌러 상태를 갱신하세요. 다중 계정·시크릿 모드·중국 미요사 계정은 지원 대상이 아닙니다.

## 자동출석 동작과 제한

크롬이 실행 중일 때 30분 간격으로 확인합니다. 크롬이 완전히 종료되어 있거나 컴퓨터가 꺼져 있으면 실행되지 않습니다. 재실행 시 오늘 출석을 확인하지만, 지난 날짜의 보상을 소급 수령하지 않습니다. 절전 상태나 브라우저 알람 지연 때문에 정확히 오전 1시에 실행되는 것은 보장하지 않습니다.

로그인 만료나 보안 인증이 표시되면 공식 출석 페이지에서 로그인·인증을 완료한 뒤 **지금 출석하기**로 다시 시도하세요. 이러한 오류와 알 수 없는 API 오류는 같은 날짜에 자동 재시도하지 않습니다. 게임 계정 미연결 등 오류도 공식 페이지에서 확인할 수 있습니다.

호요랩 출석 API는 공개된 안정성 계약이 없는 웹 API이므로 변경될 수 있습니다. 실제 계정의 출석 성공은 공식 페이지에서도 확인하세요. 요청 시간 제한은 요청당 15초이며, 게임 두 개는 순서대로 처리합니다.

## 권한과 데이터

- `storage`: 자동출석 설정과 최근 게임별 결과를 기기에 저장합니다.
- `alarms`: 자동 확인 작업을 예약합니다.
- 두 출석 API 호스트 접근: `sg-hk4e-api.hoyolab.com`, `sg-public-api.hoyolab.com`으로 요청합니다.
- `declarativeNetRequestWithHostAccess`: 확장프로그램이 두 출석 API 경로로 보내는 요청에 공식 웹 Origin·Referer를 설정합니다. 다른 사이트의 요청에는 적용하지 않습니다.

로그인 쿠키는 브라우저가 `credentials: include` 요청에 첨부합니다. 확장프로그램은 쿠키를 읽거나 별도로 저장하지 않으며, 비밀번호·토큰 입력을 받지 않습니다. 서버 원문 응답도 저장하지 않습니다. 저장되는 정보는 설정과 게임별 출석 결과·확인 시각·출석 일수뿐입니다. 외부 분석·수집 서버는 없습니다.

로그인했는데도 로그인 오류가 계속되면 공식 페이지 로그인 상태, 브라우저 쿠키 정책, 사용하는 크롬 프로필이 같은지 확인하세요. 인증 정보를 채팅이나 이슈에 붙여 넣지 마세요.

## 개발 및 검증

Node.js 22 이상을 권장합니다.

```sh
npm ci
npm test
npm run check
```

UI 테스트에는 Playwright의 Chromium이 필요합니다.

```sh
npx playwright install chromium
npm run test:ui
```

이미 설치된 Chromium을 사용하려면:

```sh
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:ui
```

런타임 의존성은 없으며 Playwright는 UI 테스트용 개발 의존성입니다.

### 자동 검증 범위

- API 모의 응답으로 두 게임의 출석 전후 확인, 이미 출석, 로그인 만료, 보안 인증, HTTP 오류, 변경된 응답 형식 검증
- 모의 Chrome API로 서비스 워커 설정·알람 생성, 게임별 실패 분리, 자동 중복 방지, 수동/자동 동시 실행 검증
- 실제 Chromium의 일반 페이지에서 모의 Chrome API로 팝업 설정·성공/오류 표시·게임 미선택 상태 검증

현재 클라우드 Chromium은 관리자 정책으로 압축해제 확장 로딩이 차단되어 있습니다. 따라서 실제 MV3 로딩, 실제 쿠키 첨부 및 계정 보상 수령은 이 환경에서 검증하지 못했습니다. 자동 테스트 통과는 실제 호요랩 계정 연동 성공을 뜻하지 않습니다.

### 실제 계정으로 확인할 항목

1. 확장프로그램 로딩 후 `chrome://extensions`에 오류가 없는지 확인합니다.
2. 두 게임에 각각 **지금 출석하기**를 실행하고 공식 페이지의 출석 상태와 대조합니다.
3. 재실행 시 이미 출석으로 표시되는지 확인합니다.
4. 자동출석을 켜고 다음 출석 날짜의 결과가 갱신되는지 확인합니다.
5. 크롬 종료 후 재실행 시 오늘 미처리 출석을 확인하는지 점검합니다.

## 구조

```text
extension/
  manifest.json       Chrome 확장 설정
  background.js       알람, 실행 관리, 결과 저장
  lib/games.js        게임별 API와 공식 출석 페이지
  lib/checkin.js      출석 API 요청과 오류 분류
  lib/state.js        설정 및 UTC+8 날짜/재시도 계산
  popup.html/css/js   한국어 팝업 화면
scripts/
  popup-smoke.mjs     브라우저 UI 검증 (모의 Chrome API)
tests/
  checkin.test.js     출석 및 날짜/재시도 테스트
  background.test.js  서비스 워커 테스트 (모의 Chrome API)
```

게임별 출석 API 경로·활동 ID·헤더는 `genshin.py`의 [routes.py](https://github.com/thesadru/genshin.py/blob/master/genshin/client/routes.py)와 [daily.py](https://github.com/thesadru/genshin.py/blob/master/genshin/client/components/daily.py)를 참고해 확인했습니다. 코드는 이 저장소에서 별도로 구현했습니다.
