# HOYO All-in-one

원신과 붕괴: 스타레일의 출석·프로필·콘텐츠 전적·가챠 계획을 관리하는 Chrome Manifest V3 확장프로그램입니다.

## 현재 기능

- 원신·스타레일 게임별 자동출석 설정 (상세 페이지에서 수동 출석 확인도 가능)
- 사용자가 켜는 자동출석 (초기 설정: 꺼짐)
- 크롬 시작·팝업 열기·30분 주기 알람에 따른 출석 확인
- 한국 시간 오전 1시(UTC+8 자정)를 기준으로 날짜 변경
- 출석 완료 여부를 서버에서 재조회한 뒤 결과 저장
- 오늘 출석 완료한 게임의 자동 요청 생략
- 네트워크 오류는 최소 1시간 후 자동 재시도
- 로그인 만료·보안 인증·기타 API 오류는 반복 요청 대신 공식 페이지 안내
- 게임별 결과, 마지막 확인 시간, 이번 달 출석 일수 표시

### 팝업 (0.4.0)

- 상단 **All-in-one 상세 페이지** 버튼으로 대시보드를 엽니다.
- 처음에는 **호요랩 연동하기**를 표시합니다. 현재 브라우저의 로그인 쿠키를 이용해 연결된 게임 계정을 조회합니다. 로그인이 필요하면 호요랩을 엽니다. 로그인 후 팝업을 다시 열면 연결을 확인합니다.
- 연결이 확인되면 연동 영역을 숨깁니다. 로그인 만료가 확인되면 다시 표시합니다. 단순 네트워크 오류는 연결 해제로 간주하지 않고 마지막 확인 상태와 오류를 표시합니다.
- 게임 카드는 기본적으로 접혀 있으며, UID·모험 등급/개척 레벨·닉네임을 표시합니다. 펼침 상태는 기기에 저장합니다.
- 카드를 펼치면 출석·이번 버전 가챠·최근 엔드 콘텐츠를 각각 구분된 칸에서 확인합니다. 횟수와 `12별` 같은 핵심 결과를 크게 표시하고, 상세 통계·편성·업적은 상세 페이지에서 확인합니다. **정보 동기화**로 프로필·전적·가챠 일정을 갱신합니다.
- 팝업에는 수동 출석 버튼이 없습니다. 자동출석을 켠 게임만 자동 실행하며, 처음 연동했다고 자동출석을 켜지는 않습니다.

### 대시보드 (0.2.0)

팝업의 **All-in-one 상세 페이지**로 상세 페이지를 엽니다. 상단에서 원신·스타레일을 바꾸고, 왼쪽 메뉴에서 개요·콘텐츠 전적·가챠 기록·픽업 계획·캐릭터를 선택합니다.

- **프로필**: 호요랩 쿠키로 연결된 게임 계정 목록을 조회하고 UID·서버·닉네임·계정 레벨을 표시합니다. 여러 서버의 게임 계정은 선택할 수 있습니다. 전적 API에서 활동 일수·보유 캐릭터 수·업적을 조회합니다.
- **원신 전적**: 나선 비경 최근/이전 회차의 요약·층별 결과·편성, 환상극 회차 요약·제공되는 막별 결과를 표시합니다.
- **스타레일 전적**: 혼돈의 기억·허구 이야기·종말의 환영 최근/이전 회차의 별·진행·층별 결과·편성·제공되는 점수를 표시합니다. 캐릭터 이름이 없는 응답은 ID로 표시합니다.
- **보관**: UID·서버별로 성공적으로 조회한 전적을 최대 60회차 보관합니다. 과거 전체 전적을 복원하는 기능은 아닙니다.
- **가챠 기록**: UIGF v4의 `hk4e`/`hkrpg` 계정별 JSON 목록, 원신 UIGF 목록, 스타레일 SRGF 목록을 가져옵니다. 5MB 이하, 계정별 50,000건까지 지원합니다. 게임·UID별 분리, ID 중복 제거, 가져온 범위 내 최근 30일 횟수·배너별 통계·최신 100건을 표시합니다. ID는 정밀도 손실을 막기 위해 문자열이어야 합니다.
- **픽업 계획**: 원석/성옥·이벤트 티켓·스택·픽업 확정 여부를 직접 입력합니다. 캐릭터 이벤트 배너의 최대 90회 규칙으로 다음 5성/픽업 확보의 상한과 부족한 횟수를 계산합니다. 게임별로 기기에 저장하며, 서버별 재화 자동 동기화는 하지 않습니다.
- **가챠 일정/버전 집계**: 원신 `act_calendar`와 스타레일 `get_act_calender`로 서버별 호요랩 픽업 일정을 조회합니다. 팝업에는 해당 버전의 제공된 픽업 기간에 수행한 기원/워프 총횟수와 캐릭터·무기/광추·상시 유형별 횟수를 표시합니다. 상세 페이지 가챠 기록 메뉴에는 배너별 시작·종료 시각과 집계 기준을 표시합니다.
- **개인 일정**: 직접 입력한 목표 픽업·한국 기준 시작 날짜와 D-day도 별도로 표시합니다.
- **캐릭터**: 프로필 API에 포함된 캐릭터 목록을 표시합니다. 전체 보유 목록과 다를 수 있습니다.

**아직 미구현:** 게임 기록 URL에서 직접 가챠 수집, 유물/성유물 평가 점수, 신규/추가 엔드 콘텐츠, 디스코드 웹후크. 준비 중인 기능에 가짜 데이터나 점수를 표시하지 않습니다.

### 이번 버전 가챠 횟수 확인

1. 팝업에서 게임을 펼쳐 **정보 동기화**를 누르거나 상세 페이지에서 **호요랩 동기화**를 실행합니다.
2. 상세 페이지의 가챠 기록 메뉴에서 해당 UID의 UIGF/SRGF JSON을 가져옵니다.
3. 팝업의 **이번 버전 기원/워프**에서 합계와 유형별 횟수를 확인합니다.

상시는 호요랩이 제공한 같은 버전 기간의 기록으로 집계하며 초보자 배너는 제외합니다. 동시에 열린 캐릭터 픽업은 개별 픽업 캐릭터를 구별할 수 없어 유형별로 합산합니다. 겹치는 일정 때문에 같은 기록을 여러 번 세지는 않습니다.

호요랩이 제공한 기간과 이 기기에 보관한 같은 버전의 이전 픽업 기간만 사용합니다. 일정 API가 이전 기간을 제공하지 않았거나 가져온 가챠 기록이 누락된 경우, 버전 전체 횟수보다 적을 수 있습니다. 버전이 바뀌면 새 일정으로 전환합니다. 기간이 만료되거나 일정/기록이 없을 때는 확인·갱신·가져오기 안내를 표시하며 임의의 `0회`를 표시하지 않습니다. 일정 조회 실패 시 마지막으로 저장한 일정을 유지하지만, 만료된 기간을 현 버전으로 집계하지 않습니다.

### 기존 설치 업데이트

```sh
git switch main
git pull origin main
```

`chrome://extensions`에서 HOYO All-in-one의 **새로고침**을 누르고 기존 대시보드 탭도 새로고침하세요. 팝업의 **All-in-one 상세 페이지**에서 **호요랩 동기화**를 실행합니다. 스타레일 전적 조회를 위해 `bbs-api-os.hoyolab.com` 접근 권한을 추가했습니다.

동기화가 실패하면 마지막으로 저장한 데이터를 남기고 실패 안내를 표시합니다. 전적 비공개·보안 인증·로그인 오류는 호요랩에서 확인 후 다시 시도하세요. 확장프로그램이 전적 공개 설정을 자동 변경하지는 않습니다.

## 크롬에 설치하기

Chrome 120 이상을 사용하세요. 확장프로그램 실행에는 Node.js나 빌드 작업이 필요하지 않습니다.

1. 이 저장소를 내려받습니다.
2. 크롬에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. 저장소의 **extension 폴더**를 선택합니다. 이 폴더 바로 아래에 `manifest.json`이 있습니다.
6. 팝업의 **호요랩 연동하기**를 누릅니다. 호요랩이 열리면 로그인하고 팝업을 다시 엽니다.
7. 연결된 프로필 카드가 표시되고 연동 버튼이 숨겨지는지 확인합니다.
8. 원하는 게임 카드를 펼쳐 **자동출석**을 켜고, 해당 카드에서 출석 결과를 확인합니다.

배포 ZIP을 사용할 경우, 먼저 압축을 풀고 `manifest.json`이 들어 있는 폴더를 로드하세요.

확장프로그램은 현재 해당 크롬 프로필에 로그인한 호요랩 계정 하나를 사용합니다. 계정을 변경하거나 로그인을 다시 했다면 팝업을 다시 열어 연결을 확인하고, **정보 동기화**로 프로필을 갱신하세요. 다중 계정·시크릿 모드·중국 미요사 계정은 지원 대상이 아닙니다.

## 자동출석 동작과 제한

크롬이 실행 중일 때 30분 간격으로 확인합니다. 크롬이 완전히 종료되어 있거나 컴퓨터가 꺼져 있으면 실행되지 않습니다. 재실행 시 오늘 출석을 확인하지만, 지난 날짜의 보상을 소급 수령하지 않습니다. 절전 상태나 브라우저 알람 지연 때문에 정확히 오전 1시에 실행되는 것은 보장하지 않습니다.

로그인 만료나 보안 인증이 표시되면 공식 출석 페이지에서 로그인·인증을 완료한 뒤 **지금 출석하기**로 다시 시도하세요. 로그인 만료 오류는 팝업에서 로그인 복구를 확인하면 자동출석을 켠 게임에 한해 재시도합니다. 보안 인증 오류와 알 수 없는 API 오류는 같은 날짜에 반복 자동 재시도하지 않습니다. 게임 계정 미연결 등 오류도 공식 페이지에서 확인할 수 있습니다.

호요랩 출석 API는 공개된 안정성 계약이 없는 웹 API이므로 변경될 수 있습니다. 실제 계정의 출석 성공은 공식 페이지에서도 확인하세요. 요청 시간 제한은 요청당 15초이며, 게임 두 개는 순서대로 처리합니다.

## 권한과 데이터

- `storage`: 호요랩 연결 확인 상태·게임 계정 목록·카드 펼침 상태, 출석 설정·결과, 게임 계정·프로필·전적, 가져온 가챠 기록, 직접 입력한 계획을 기기에 저장합니다. Chrome 기본 로컬 저장 용량을 초과하면 저장이 실패할 수 있습니다.
- `alarms`: 자동 확인 작업을 예약합니다.
- 호요랩 API 호스트 접근: 출석·계정·원신 전적에 `sg-hk4e-api.hoyolab.com`, `sg-public-api.hoyolab.com`, 스타레일 전적에 `bbs-api-os.hoyolab.com`으로 요청합니다.
- `declarativeNetRequestWithHostAccess`: 확장프로그램이 출석·계정·전적 API 경로로 보내는 요청에 공식 웹 Origin·Referer를 설정합니다. 다른 사이트의 요청에는 적용하지 않습니다.

로그인 쿠키는 브라우저가 `credentials: include` 요청에 첨부합니다. 확장프로그램은 쿠키를 읽거나 별도로 저장하지 않으며, 비밀번호·토큰 입력을 받지 않습니다. 서버 원문 응답도 저장하지 않습니다. UID·서버·프로필 통계와 정리된 전적, 가져온 가챠 기록, 개인 계획과 정리된 픽업 일정도 기기에 저장됩니다. 가챠 JSON의 알 수 없는 필드나 인증 토큰은 보관하지 않습니다. 외부 분석·수집 서버는 없습니다.

로그인했는데도 로그인 오류가 계속되면 공식 페이지 로그인 상태, 브라우저 쿠키 정책, 사용하는 크롬 프로필이 같은지 확인하세요. 인증 정보를 채팅이나 이슈에 붙여 넣지 마세요.

## 개발 및 검증

Node.js 22 이상을 권장합니다.

```sh
npm ci
npm test
npm run check
```

UI 테스트에는 Playwright의 Chromium이 필요합니다.

```sh
npx playwright install chromium
npm run test:ui
```

이미 설치된 Chromium을 사용하려면:

```sh
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:ui
```

런타임 의존성은 없으며 Playwright는 UI 테스트용 개발 의존성입니다.

### 자동 검증 범위

- API 모의 응답으로 두 게임의 출석 전후 확인, 이미 출석, 로그인 만료, 보안 인증, HTTP 오류, 변경된 응답 형식 검증
- 모의 Chrome API로 서비스 워커 설정·알람 생성, 게임별 실패 분리, 자동 중복 방지, 수동/자동 동시 실행 검증
- 기록 API 모의 응답으로 계정 선택·서명·프로필 공개 오류·콘텐츠별 스키마·게임별 캘린더 GET/POST 및 오류 격리 검증
- 버전 집계에서 시작/종료 경계·동시 픽업 중복 방지·상시 포함·초보자 제외·미래 기록 제외·기간 만료·같은 버전 기간 보관 검증
- JSON 가져오기에서 정밀한 ID·중복·게임/UID 분리·잘못된 날짜 검증, 천장 상한·한국 날짜 계산 검증
- 실제 Chromium의 일반 페이지에서 모의 Chrome API로 팝업과 대시보드의 탭·동기화 화면·전적 상세·파일 가져오기·계획 저장·모바일 화면·안전한 텍스트 표시 검증

현재 클라우드 Chromium은 관리자 정책으로 압축해제 확장 로딩이 차단되어 있습니다. 기존 출석 기능은 사용자가 실제 크롬에서 정상 동작을 확인했습니다. 새 프로필·전적·일정 API의 인증된 실제 계정 조회는 이 환경에서 검증하지 못했습니다. 자동 테스트 통과는 새 호요랩 API 연동 성공을 뜻하지 않습니다.

### 실제 계정으로 확인할 항목

1. 확장프로그램 로딩 후 `chrome://extensions`에 오류가 없는지 확인합니다.
2. 팝업에서 호요랩 연결을 확인하고 원하는 게임의 자동출석을 켭니다.
3. 카드의 출석 결과가 공식 페이지의 상태와 일치하는지, 완료된 출석을 중복 실행하지 않는지 확인합니다.
4. 자동출석을 켜고 다음 출석 날짜의 결과가 갱신되는지 확인합니다.
5. 크롬 종료 후 재실행 시 오늘 미처리 출석을 확인하는지 점검합니다.
6. 대시보드에서 두 게임을 동기화하고 UID·레벨·프로필 통계를 호요랩과 대조합니다.
7. 각 콘텐츠의 별·점수·회차·층별 편성이 호요랩과 일치하는지 확인합니다.
8. 사용 중인 도구에서 내보낸 UIGF/SRGF JSON을 가져와 UID와 최신 기록을 대조합니다.
9. 호요랩 일정의 버전·서버별 기간과 상세 페이지 일정을 대조하고, 그 기간의 픽업 횟수가 팝업 집계와 일치하는지 확인합니다.

### 스타레일 공식 워프 통계 (0.4.0)

[공식 워프 통계](https://act.hoyolab.com/sr/event/gt-aio/gacha-records/index.html?lang=ko-kr#/index-pc)를 **정보 동기화**에 연결했습니다. `sg-act-public-api.hoyolab.com/common/badge/v1/login/account`로 게임별 로그인 쿠키를 발급받고 `event/rpg_gacha_record/pool_stat` 및 `five_star_list`를 조회합니다. 토큰을 읽거나 저장하지 않습니다. 이 호스트에 대한 새 권한이 필요할 수 있습니다.

- 팝업 글자 크기를 0.3.1 대비 10% 줄였습니다. 공식 최근 캐릭터 5성의 이미지가 제공되면 함께 표시합니다.
- 공식 배너 통계의 버전과 서버별 일정 버전이 일치하는 카드만 합산합니다. 상시 등 버전별 카드가 제공되지 않은 값은 `확인 필요`로 표시합니다. 공식 버전 통계가 없으면 가져온 JSON으로 집계합니다.
- 마지막 5성 이후 횟수와 공식 `is_up` 값을 사용합니다. 비픽업 5성 이후에는 픽업 확정, 픽업 5성 이후에는 미확정으로 계산합니다. 캐릭터 최대 90회, 광추 최대 80회를 적용하며 남은 횟수는 평균이 아닌 **최대 필요 횟수**입니다. 상시는 다음 5성까지 표시합니다. 콜라보 배너는 별도이며 현재 집계에서 제외됩니다.
- 상세 페이지에서 캐릭터·광추·상시의 최근 5성 5건과 픽업 여부를 확인합니다. 공식 요약 통계는 모든 3·4성 개별 기록을 대체하지 않으므로 기존 JSON 가져오기도 유지합니다.
- 조회 실패는 프로필·출석·다른 배너 조회를 막지 않습니다. 공식 페이지에서 로그인이나 인증을 완료한 뒤 다시 동기화하세요. 기록이 없으면 확정 여부를 추측하지 않습니다. 원신의 버전 횟수·스택은 가져온 JSON 기준이며 무기 운명 포인트 자동 판정은 지원하지 않습니다.

검증: Node 단위 테스트 및 Chrome API를 모의한 Chromium 화면 테스트. 실제 로그인 계정의 공식 API 응답은 이 환경에서 검증하지 못했으므로 브라우저에서 원본 통계와 비교해야 합니다.

공식 전적 및 가챠 일정 대조 페이지:

- [스타레일 전적](https://act.hoyolab.com/app/community-game-records-sea/rpg/index.html?gid=6#/hsr)

상세 페이지의 개요와 가챠 기록 메뉴에 게임별 공식 페이지 링크를 제공합니다. 전적 및 일정은 이미 연결한 HoYoLAB API로 조회하며 웹페이지 HTML을 스크래핑하지 않습니다.
